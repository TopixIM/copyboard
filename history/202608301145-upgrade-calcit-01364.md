# Calcit 0.13.64 upgrade / 升级记录

## 中文

- 将 `:calcit-version` 与 `@calcit/procs` 同步到 0.13.64，并通过 Caps 升级全部稳定模块。
- 将历史固定 hash 的 `Respo/alerts.calcit` 改为稳定发布 tag `0.10.22`；`caps reset` 后确认模块链接确实指向该 release。
- 将应用中的 `get-or` 迁移为 `get` 返回 Option 后调用 `.unwrap-or`，并让 Respo 事件回调显式返回 `&unit`，消除严格预处理告警。
- 移除 `calcit.cirru` 的 generated/diff 隐藏属性。新版 formatter 将 Snapshot 定义键规范化为 symbol，读取仍兼容旧 string 格式。
- 验证：`calcit calcit.cirru --check-only`、`yarn compile-page`、`caps status`、`yarn smoke-server` 均通过；smoke 前后 `storage.cirru` SHA-256 相同。

## English

- Align `:calcit-version` and `@calcit/procs` at 0.13.64 and upgrade all stable modules through Caps.
- Replace the historical pinned `Respo/alerts.calcit` commit with stable tag `0.10.22`; verify the resolved module link after `caps reset`.
- Migrate application `get-or` calls to `get` plus Option `.unwrap-or`, and return explicit `&unit` from Respo event handlers to clear strict preprocessing warnings.
- Remove the generated/diff-hidden attribute from `calcit.cirru`. The new formatter canonicalizes Snapshot definition keys to symbols while retaining legacy string-read compatibility.
- Verified with `calcit calcit.cirru --check-only`, `yarn compile-page`, `caps status`, and `yarn smoke-server`; the SHA-256 of `storage.cirru` was unchanged before and after smoke.
